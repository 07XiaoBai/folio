# Des Pradilla — Portfolio

Static personal portfolio (plain HTML / CSS / JS, no build step) published with GitHub Pages at
https://07xiaobai.github.io/folio/

- `index.html` — all content. Case studies live in `.case-library` blocks; the clickable maps open them in a dialog (`js/main.js`). Without JavaScript the full case list shows instead.
- `css/styles.css` — sky / cream / peach design; decorations are original CSS + inline SVG.
- `images/` — photos and campaign creatives. Favicons sit in the root.
- Contact form posts to Web3Forms (`dtpradilla@gmail.com`).

All paths are relative, so the folder can be pushed as-is. Preview locally by opening `index.html`.
