# Des Pradilla — Personal Portfolio

Static personal portfolio site for **Des Pradilla**, showcasing digital marketing work for leisure, attractions, and outdoor ecommerce — including **GC Aqua Park (GCAP)** since 2020, **Gold Coast Wake Park**, and Shopify store experience.

Built as plain HTML / CSS / JS for free hosting on **GitHub Pages** (no WordPress required).

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
# Python
python3 -m http.server 8080

# or Node
npx --yes serve .
```

Then visit `http://localhost:8080`.

## Publish on GitHub Pages (later)

1. Create a repo (e.g. `07XiaoBai.github.io` for a user site, or any repo with Pages enabled).
2. Push the contents of this folder to the default branch (or `docs/` / `gh-pages`, depending on Pages settings).
3. In the repo **Settings → Pages**, set the source to the branch/folder that contains `index.html`.
4. Site URL for a user site is typically `https://07XiaoBai.github.io`.

Do not push until Des has reviewed copy, placeholders, and which commercial figures stay public.

## What’s included

- Hero covering leisure / attractions / outdoor ecommerce (GCAP since 2020)
- Capabilities including Shopify store management
- Experience section: six Shopify brands (4+ years framing) + GCWP work mention
- Eight GCAP case studies (2025 campaigns + 2026 website/funnel process)
